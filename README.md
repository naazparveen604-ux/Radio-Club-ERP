# 📻 Radio Club ERP

## Radio Club Enterprise Resource Planning System

Radio Club ERP is a centralized web-based management system designed to simplify and organize the activities of a college Radio Club. The system helps manage members, programs, events, tasks, announcements, resources, and club activities through a single platform.

---

## 🎯 Project Objective

The main objective of **Radio Club ERP** is to provide a digital platform for managing Radio Club operations efficiently.

It helps reduce manual paperwork, improve communication, organize club activities, and provide easy access to important information.

---

## ✨ Key Features

### 👥 Member Management

* Add and manage Radio Club members
* Maintain member information
* Track member participation
* Organize members according to their roles

### 📅 Event Management

* Create and manage radio club events
* Maintain event schedules
* Track upcoming and completed events
* Manage event-related activities

### 📢 Announcements

* Publish important club announcements
* Share updates with members
* Keep members informed about upcoming activities

### 📋 Task Management

* Assign tasks to club members
* Track task progress
* Manage deadlines
* Monitor completed and pending tasks

### 🎙️ Radio Program Management

* Manage radio programs
* Maintain program schedules
* Organize presenters and participants
* Track program-related information

### 📚 Resource Management

* Store and organize important club resources
* Manage documents and files
* Provide centralized access to required information

### 📊 Dashboard

* View important club information in one place
* Monitor activities
* Track events, tasks, members, and announcements
